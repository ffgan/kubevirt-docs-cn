# 欢迎 {#welcome}

KubeVirt 用户指南分为以下部分：

* 架构：KubeVirt 组件的技术与概念概述
* 快速开始：帮助你学习 KubeVirt 基础知识的资源列表
* 集群管理：集群级别的管理概念与任务
* 用户工作负载：创建、自定义、使用和监控虚拟机
* 计算：虚拟化层的资源分配与优化
* 网络：网络层与服务层的概念与任务
* 存储：存储层的概念与任务，包括导入和导出。
* 发行说明：所有 KubeVirt 发行版的发行说明
* 贡献：如何为本指南或 KubeVirt 项目做贡献
* 虚拟化调试：如何调试你的 KubeVirt 集群和虚拟资源
